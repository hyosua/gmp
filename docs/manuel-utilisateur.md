# Manuel d'utilisateur - Site GMP

## 1. Introduction

### 1.1 Présentation du site

Le site du département Génie Mécanique et Productique (GMP) de l'IUT d'Évry est
une plateforme institutionnelle accessible depuis n'importe quel navigateur web.

Il remplit deux fonctions principales :

- **Informer** : les visiteurs non connectés peuvent consulter la présentation du
  département, les formations proposées (BUT GMP, Licences Professionnelles) et
  les modalités d'accès.
- **Gérer** : les utilisateurs connectés disposent d'un espace personnalisé selon
  leur rôle - étudiant, enseignant, entreprise ou administrateur.

### 1.2 Comment lire ce manuel

Ce manuel est organisé par rôle. Rendez-vous directement à la section qui vous
correspond :

| Vous êtes...   | Section à consulter |
| -------------- | ------------------- |
| Étudiant       | Section 3           |
| Enseignant     | Section 4           |
| Entreprise     | Section 5           |
| Administrateur | Section 6           |

La section 2 (Connexion et accès) est utile à tous les utilisateurs connectés.

> Les captures d'écran et exemples de ce manuel correspondent à la version
> actuelle du site. L'interface peut évoluer sans que ce document soit
> immédiatement mis à jour.

## 2. Connexion et accès

### 2.1 Se connecter

1. Depuis n'importe quelle page du site, cliquez sur le bouton **Connexion**
   visible dans la barre de navigation.
2. Saisissez votre **adresse e-mail** et votre **mot de passe**.
3. Cliquez sur **Se connecter**.

Vous êtes automatiquement redirigé vers votre espace personnel selon votre rôle :

| Rôle           | Redirection après connexion |
| -------------- | --------------------------- |
| Étudiant       | Espace étudiant             |
| Enseignant     | Espace enseignant           |
| Entreprise     | Espace entreprise           |
| Administrateur | Panel d'administration      |

> Vos identifiants vous sont fournis par le département GMP. Si vous n'avez pas
> encore reçu vos accès ou si vous avez oublié votre mot de passe, contactez
> l'administration du département.

### 2.2 Se déconnecter

Un bouton **Déconnexion** est disponible dans la barre latérale de votre espace
personnel. Cliquez dessus pour mettre fin à votre session.

> Il est recommandé de vous déconnecter à chaque fin de session, en particulier
> sur un ordinateur partagé.

### 2.3 Accès refusé

Si vous tentez d'accéder à une page protégée sans être connecté, vous êtes
automatiquement redirigé vers la page de connexion.

Si vous êtes connecté mais que vous n'avez pas les droits nécessaires pour
accéder à une page, un message d'erreur s'affiche. Vérifiez que vous utilisez
bien le compte correspondant à votre rôle.

## 3. Espace Étudiant

Accessible après connexion avec un compte étudiant. La barre latérale gauche
permet de naviguer entre les différentes rubriques.

### 3.1 Consulter ses notes

1. Dans la barre latérale, cliquez sur **Notes**.
2. La liste de vos notes s'affiche, organisée par matière.
3. La moyenne par matière est calculée automatiquement.

> Les notes sont en lecture seule. Toute contestation doit être adressée
> directement à l'enseignant concerné.

### 3.2 Voir son emploi du temps

1. Dans la barre latérale, cliquez sur **Emploi du temps**.
2. Le planning de la semaine en cours s'affiche avec les créneaux, salles et
   intitulés de cours.
3. Utilisez les flèches de navigation pour passer d'une semaine à l'autre.

### 3.3 Télécharger des supports de cours

1. Dans la barre latérale, cliquez sur **Supports de cours**.
2. La liste des PDFs déposés par vos enseignants s'affiche.
3. Cliquez sur un support pour le télécharger.

> Le téléchargement nécessite d'être connecté. Les fichiers ne sont pas
> accessibles par lien direct.

### 3.4 Consulter les projets tuteurés

1. Dans la barre latérale, cliquez sur **Projets tuteurés**.
2. La liste des projets proposés par les entreprises partenaires s'affiche.
3. Cliquez sur un projet pour en consulter le détail : entreprise, description,
   prérequis, nombre d'étudiants souhaité.

> La liste est en lecture seule. Pour candidater, rapprochez-vous du département.

### 3.5 Consulter les offres d'alternance

1. Dans la barre latérale, cliquez sur **Offres d'alternance**.
2. La liste des offres ouvertes s'affiche.
3. Cliquez sur une offre pour en consulter le détail : entreprise, poste, durée,
   rémunération, prérequis.

> Pour postuler à une offre, rapprochez-vous du département GMP.

## 4. Espace Enseignant

Accessible après connexion avec un compte enseignant. La barre latérale gauche
permet de naviguer entre les différentes rubriques.

### 4.1 Gérer ses notes

#### Consulter ses notes déposées

1. Dans la barre latérale, cliquez sur **Notes**.
2. La liste des notes que vous avez saisies s'affiche, filtrée par matière.

#### Ajouter une note

1. Sur la page Notes, cliquez sur **Ajouter une note**.
2. Remplissez le formulaire :
   - **Étudiant** : sélectionnez l'étudiant dans la liste.
   - **Matière** : sélectionnez la matière concernée.
   - **Note** : saisissez une valeur entre 0 et 20.
3. Cliquez sur **Enregistrer**.

#### Modifier une note

1. Sur la page Notes, repérez la note à modifier.
2. Cliquez sur l'icône de modification.
3. Corrigez la valeur, puis cliquez sur **Enregistrer**.

> Vous ne pouvez modifier que vos propres notes.

### 4.2 Voir son emploi du temps

1. Dans la barre latérale, cliquez sur **Emploi du temps**.
2. Votre planning personnel de la semaine en cours s'affiche.
3. Utilisez les flèches de navigation pour passer d'une semaine à l'autre.

### 4.3 Gérer ses supports de cours

#### Déposer un support

1. Dans la barre latérale, cliquez sur **Dépôt de cours**.
2. Cliquez sur **Choisir un fichier** et sélectionnez un PDF (taille max : 20 Mo).
3. Saisissez un **titre** pour le support.
4. Cliquez sur **Envoyer**.

> Seuls les fichiers au format PDF sont acceptés.

#### Consulter et supprimer ses supports

1. Sur la même page, la liste de vos supports déposés s'affiche.
2. Pour supprimer un fichier, cliquez sur l'icône de suppression en face du
   support concerné.
3. Confirmez la suppression dans la boîte de dialogue.

> Vous ne pouvez supprimer que vos propres supports. La suppression est
> définitive.

## 5. Espace Entreprise

Accessible après connexion avec un compte entreprise. La barre latérale gauche
permet de naviguer entre les différentes rubriques.

### 5.1 Gérer ses projets tuteurés

#### Consulter ses projets

1. Dans la barre latérale, cliquez sur **Projets tuteurés**.
2. La liste de vos projets déposés s'affiche avec leur statut actuel.

#### Créer un projet

1. Sur la page Projets tuteurés, cliquez sur **Nouveau projet**.
2. Remplissez le formulaire :
   - **Titre** : intitulé du projet.
   - **Description** : présentation détaillée du projet et des missions attendues.
   - **Prérequis** : compétences ou connaissances requises de la part des étudiants.
   - **Nombre d'étudiants souhaité** : indiquez le nombre de places disponibles.
3. Cliquez sur **Enregistrer**.

> Après dépôt, votre projet est soumis à validation par l'administration avant
> d'être visible par les étudiants.

#### Modifier un projet

1. Sur la page Projets tuteurés, repérez le projet à modifier.
2. Cliquez sur l'icône de modification.
3. Apportez vos corrections, puis cliquez sur **Enregistrer**.

> Vous ne pouvez modifier que vos propres projets.

### 5.2 Gérer ses offres d'alternance

#### Consulter ses offres

1. Dans la barre latérale, cliquez sur **Offres d'alternance**.
2. La liste de vos offres déposées s'affiche.

#### Créer une offre

1. Sur la page Offres d'alternance, cliquez sur **Nouvelle offre**.
2. Remplissez le formulaire :
   - **Poste** : intitulé du poste proposé.
   - **Description** : détail des missions et du contexte.
   - **Durée** : durée du contrat ou du stage.
   - **Rémunération** : montant ou fourchette de rémunération.
   - **Prérequis** : compétences requises.
3. Cliquez sur **Enregistrer**.

#### Modifier une offre

1. Sur la page Offres d'alternance, repérez l'offre à modifier.
2. Cliquez sur l'icône de modification.
3. Apportez vos corrections, puis cliquez sur **Enregistrer**.

> Vous ne pouvez modifier que vos propres offres.

## 6. Panel d'administration

Accessible après connexion avec un compte administrateur (personnel GMP
uniquement). L'administrateur dispose d'un accès complet à l'ensemble du
contenu du site.

### 6.1 Gérer les utilisateurs

#### Consulter la liste des utilisateurs

1. Dans la barre latérale, cliquez sur **Utilisateurs**.
2. La liste de tous les comptes enregistrés s'affiche avec leur nom, e-mail
   et rôle.

#### Créer un utilisateur

1. Sur la page Utilisateurs, cliquez sur **Nouvel utilisateur**.
2. Remplissez le formulaire :
   - **Prénom / Nom**
   - **Adresse e-mail**
   - **Rôle** : Étudiant, Enseignant, Entreprise ou Administrateur.
   - **Mot de passe provisoire** : communiqué à l'utilisateur par vos soins.
3. Cliquez sur **Enregistrer**.

#### Modifier le rôle d'un utilisateur

1. Sur la page Utilisateurs, repérez le compte concerné.
2. Cliquez sur l'icône de modification.
3. Changez le rôle dans le menu déroulant, puis cliquez sur **Enregistrer**.

#### Désactiver un compte

1. Sur la page Utilisateurs, repérez le compte à désactiver.
2. Cliquez sur l'icône de désactivation.
3. Confirmez l'action dans la boîte de dialogue.

> Un compte désactivé ne peut plus se connecter. Il n'est pas supprimé et peut
> être réactivé à tout moment.

### 6.2 Gérer les notes

1. Dans la barre latérale, cliquez sur **Notes**.
2. La liste de toutes les notes saisies par l'ensemble des enseignants s'affiche.
3. Vous pouvez modifier ou supprimer n'importe quelle note, quel que soit
   l'enseignant qui l'a saisie.

> Utilisez les filtres disponibles (par enseignant, par matière, par étudiant)
> pour affiner l'affichage.

### 6.3 Gérer les projets tuteurés

1. Dans la barre latérale, cliquez sur **Projets tuteurés**.
2. La liste de tous les projets déposés par les entreprises s'affiche, avec
   leur statut : **En attente**, **Validé** ou **Refusé**.

#### Valider ou refuser un projet

1. Repérez le projet à traiter.
2. Cliquez sur **Valider** pour le rendre visible aux étudiants, ou sur
   **Refuser** pour le rejeter.

> Un projet validé est immédiatement visible dans l'espace étudiant.
> Un projet refusé reste visible par l'entreprise concernée.

#### Modifier ou supprimer un projet

1. Cliquez sur l'icône de modification ou de suppression en face du projet.
2. Confirmez l'action si une confirmation est demandée.

### 6.4 Gérer les offres d'alternance

1. Dans la barre latérale, cliquez sur **Offres d'alternance**.
2. La liste de toutes les offres déposées par les entreprises s'affiche.
3. Vous pouvez modifier ou supprimer n'importe quelle offre.

### 6.5 Gérer les supports de cours

1. Dans la barre latérale, cliquez sur **Supports de cours**.
2. La liste de tous les PDFs déposés par l'ensemble des enseignants s'affiche.
3. Vous pouvez supprimer n'importe quel support, quel que soit l'enseignant
   qui l'a déposé.

## 7. FAQ

### Je n'arrive pas à me connecter, que faire ?

Vérifiez que votre adresse e-mail est correctement saisie et que la touche
Majuscule n'est pas activée pour le mot de passe. Si le problème persiste,
contactez l'administration du département GMP pour réinitialiser vos accès.

### Je ne vois pas mes notes alors que mon enseignant dit les avoir saisies.

Actualisez la page. Si les notes n'apparaissent toujours pas, contactez
l'administration - il est possible que la note ait été associée à un autre
compte étudiant par erreur.

### Je ne trouve pas un support de cours que mon enseignant a déposé.

Vérifiez que vous êtes bien connecté avec votre compte étudiant. Si le support
n'apparaît toujours pas, demandez à votre enseignant de confirmer qu'il a bien
été déposé sur la plateforme.

### Mon fichier PDF ne s'envoie pas (espace enseignant).

Vérifiez que :

- Le fichier est bien au format **PDF**.
- Sa taille ne dépasse pas **20 Mo**.
- Votre connexion internet est stable.

Si le problème persiste, contactez l'administration.

### Mon projet tuteuré / mon offre d'alternance n'est pas visible par les étudiants.

Les projets et offres sont soumis à validation par l'administration avant
d'être publiés. Si votre dépôt date de plus de 48 heures et n'est toujours pas
visible, contactez le département GMP.

### J'ai saisi une mauvaise note, comment la corriger ?

Rendez-vous sur la page **Notes** de votre espace enseignant, repérez la note
concernée et cliquez sur l'icône de modification. Si la note a été saisie par
un autre enseignant, contactez l'administration.

### Le site ne s'affiche pas correctement sur mon téléphone.

Le site est optimisé pour les navigateurs suivants : Chrome, Firefox, Safari
et Edge (versions récentes). Essayez de vider le cache de votre navigateur ou
de mettre à jour ce dernier. Si le problème persiste, signalez-le à
l'administration.

### Je n'ai pas reçu mes identifiants de connexion.

Les identifiants sont créés et transmis par l'administration du département
GMP. Contactez-les directement pour obtenir vos accès.

## 8. Glossaire

| Terme                  | Définition                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **BUT GMP**            | Bachelor Universitaire de Technologie Génie Mécanique et Productique. Formation en 3 ans proposée par l'IUT d'Évry.  |
| **LP**                 | Licence Professionnelle. Formation de niveau Bac+3 accessible après un BUT ou un BTS.                                |
| **Espace personnel**   | Interface accessible après connexion, propre à chaque rôle (étudiant, enseignant, entreprise, admin).                |
| **Support de cours**   | Fichier PDF déposé par un enseignant et téléchargeable par les étudiants connectés.                                  |
| **Projet tuteuré**     | Projet proposé par une entreprise partenaire, réalisé par un ou plusieurs étudiants dans le cadre de leur formation. |
| **Offre d'alternance** | Proposition de contrat en alternance ou de stage déposée par une entreprise partenaire.                              |
| **Rôle**               | Niveau d'accès attribué à un compte utilisateur : Étudiant, Enseignant, Entreprise ou Administrateur.                |
| **Administrateur**     | Membre du personnel GMP disposant d'un accès complet à la gestion du site.                                           |
| **Session**            | Période pendant laquelle un utilisateur est connecté au site. La session prend fin lors de la déconnexion.           |
| **PDF**                | Format de fichier utilisé pour les supports de cours (Portable Document Format).                                     |
| **Validation**         | Action par laquelle un administrateur approuve un projet tuteuré ou une offre avant sa publication.                  |
